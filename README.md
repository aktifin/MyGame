# 化学元素消消乐 (Chemistry Match Game) 🧪

一款基于 HTML5 + CSS3 + Vanilla JavaScript 制作的趣味化学元素消除网页小游戏。

🌐 **在线试玩地址**：[https://aktifin.github.io/MyGame/](https://aktifin.github.io/MyGame/)

## 🌟 核心特色与玩法

- **4 × 5 经典网格**：每排 5 个小球，共 4 行，每次展示 10 对化学元素（10 个元素名称球 + 10 个元素符号球）。
- **立体拟物双色小球**：
  - **浅绿色底**：元素符号球（带原子序数与英文符号）；
  - **浅蓝色底**：元素名称球（带汉字与拼音注音）。
- **120 秒限时挑战**：点击“开始游戏”后启动倒计时。
- **正向积分机制**：配对成功一对加 10 分，答错晃动提示且**不扣分**。
- **元素范围快捷切换**：
  - **基础模式**：1~20 号元素（氢~钙）；
  - **常见元素模式**：前 40 号元素（增加铁、铜、锌等常见金属与非金属）。
- **原生音效**：基于 Web Audio API 动态合成消除音与提示音，无需联网加载音频资源。

## 🚀 运行方式

无需任何构建工具或依赖安装：
1. 克隆或下载本项目仓库；
2. 直接使用任意现代浏览器双击打开 `index.html` 即可畅玩。
